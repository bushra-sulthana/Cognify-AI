PROGRAMMING LANGUAGES
Python was created by Guido van Rossum and was first released in 1991. Python is a high-level, interpreted, general-purpose programming language known for readable syntax.

The Java programming language was released by Sun Microsystems in 1995. JavaScript was created by Brendan Eich in 1995 and, despite the similar name, is a different language from Java.

MACHINE LEARNING AND LLMs
The Transformer architecture was introduced in the 2017 research paper "Attention Is All You Need". It replaced recurrence with a self-attention mechanism and is the basis of modern large language models.

A large language model (LLM) predicts the next token in a sequence based on patterns learned from training data. An LLM does not look up facts in a database at inference time unless it is explicitly connected to one.

A hallucination in the context of language models is an output that is fluent and confident but factually incorrect or unsupported by any source. Hallucinations happen because the model optimises for likely text, not for truth.

Retrieval-Augmented Generation (RAG) reduces hallucination risk by retrieving relevant documents from a trusted corpus and supplying them to the model as context. RAG reduces but does not eliminate hallucinations, because retrieval can fail and the model can still ignore the evidence.

Natural Language Inference (NLI), also called textual entailment, decides whether a hypothesis is entailed by, contradicted by, or neutral with respect to a premise. NLI models are commonly used to check whether a generated claim is supported by retrieved evidence.

TOOLS
FAISS (Facebook AI Similarity Search) is an open-source library from Meta for efficient similarity search over dense vectors. Chroma is an alternative open-source vector database.

Sentence-Transformers is a Python library for computing dense sentence embeddings. The model all-MiniLM-L6-v2 produces 384-dimensional embeddings and is small enough to run on a normal laptop CPU.

Ollama is a tool that runs open-weight large language models locally on a personal computer and exposes a local HTTP server on port 11434 by default. Because Ollama runs on the local machine, no API key and no internet connection are required for inference.

FastAPI is a modern Python web framework for building APIs, based on Starlette and Pydantic, with automatic interactive documentation.
