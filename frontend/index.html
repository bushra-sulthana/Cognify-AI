      Cognify-AI reduces hallucination risk by verifying generated claims against a local knowledge base and rewriting unsupported answers. It does not eliminate hallucinations: the retriever, the entailment model and the local LLM can all be wrong, and a claim that is missing from the knowledge base is reported as unverified, not as false.

      Runs fully offline — Ollama + Sentence-Transformers + FAISS + FastAPI. No API keys. API docs at /docs.
